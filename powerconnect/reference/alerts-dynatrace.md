# Shipped Dynatrace alerts and their matchers

Generated from the product documentation ("List of Alerts - Dynatrace"). Each alert is a Davis event processor in the OpenPipeline log pipeline; a record that matches raises a `CUSTOM_ALERT` Davis event on the SAP instance entity. The matchers are the most reliable published source of Dynatrace field names, state values and default thresholds. Backslashes inside string literals are doubled here so the matchers run as DQL.
